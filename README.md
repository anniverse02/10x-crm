# 10X CRM

## Introduction

A simple CRM web application built as part of the 10X JavaScript course.

## Main Features
- Sign Up and Login
- Protected pages
- Dashboard
- Add and delete clients
- Dark mode
- LocalStorage support

## Technologies

- HTML
- CSS
- JavaScript
- DummyJSON API

## Future Improvements

- Edit client information
- Better search and filtering
- Responsive design improvements
- Better dashboard analytics
