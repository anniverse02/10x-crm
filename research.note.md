# Research

## Project Planning

Before writing any code, I carefully reviewed the project requirements and planned the structure of the application. I decided how many pages the project would have, how users would move between them, and how the application data would be organized. This planning helped me keep the project simple, organized, and easier to maintain.

---

## Form Validation

I researched different techniques for validating form inputs in JavaScript. I implemented validation for required fields, minimum password length, email format, duplicate email checking, and password confirmation. I also learned how to display clear error messages so users understand what needs to be corrected before submitting the form.

---

## Local Storage

Since this project does not use a backend, I researched how to use localStorage to store application data. I learned how to save JavaScript objects using `JSON.stringify()` and retrieve them using `JSON.parse()`. LocalStorage is used to store registered users, active sessions, client information, and the selected theme.

---

## Authentication

I researched how a simple authentication system works in frontend applications. I implemented user registration, login, logout, session management, and page protection. Users who are not logged in cannot access protected pages, while logged-in users are automatically redirected to the dashboard.

---

## Fetch API

I learned how to work with the Fetch API using `async` and `await`. The project uses the DummyJSON API to load sample client data and simulate creating and deleting clients. I also researched how to check `response.ok` and handle possible request errors.

---

## DOM Manipulation

I researched how to dynamically update HTML using JavaScript. I practiced selecting elements, modifying their content, creating new elements, updating statistics, displaying client information, and reacting to user interactions through event listeners.

---

## JavaScript Array Methods

To manage application data efficiently, I researched several array methods. I used `find()` to locate users, `filter()` to create filtered lists, `some()` to check for duplicate emails, `sort()` to order data, and `map()` when transforming information for display.

---

## Dashboard Logic

I researched different ways to calculate dashboard statistics. The dashboard automatically displays the total number of clients, active deals, revenue from won deals, recent clients, and the number of clients in each pipeline stage. This information is updated every time the page loads.

---

## Theme Management

I researched how websites remember user preferences. I implemented a dark/light theme switcher and saved the selected theme in localStorage so it remains the same after refreshing the page.

---

## User Experience

I researched simple techniques that improve user experience. The project includes validation messages, confirmation dialogs before deleting clients, automatic redirects after successful actions, and feedback messages to make the application easier to use.

---

## Git and GitHub

During development, I used Git and GitHub to manage the project. I worked with feature branches, created meaningful commits, pushed changes to GitHub, and merged completed features into the main branch. This workflow helped me keep the project organized and track every major change.

---

## Conclusion

This project allowed me to improve my understanding of JavaScript, DOM manipulation, browser storage, authentication, API requests, and application structure. It also helped me practice writing cleaner code, organizing files, and following a real development workflow using Git and GitHub.
